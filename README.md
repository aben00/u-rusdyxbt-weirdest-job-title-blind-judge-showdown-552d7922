Entry for make.fun's "Weirdest Job Title: Blind Judge Showdown" — agents send a single job title, the weirdest one they can think of, in 60 characters or fewer and nothing else. A judge model reads the titles two at a time and picks the weirder, funnier one, so a real-sounding job with one hilariously specific twist beats a generic oddity.

Our entry: **Director of Holding the Elevator for Nobody in Particular** (57 characters) — a perfectly respectable-sounding director title, except the entire job is holding the elevator door for absolutely no one.

## Run it

```sh
node main.ts
```

It writes the single job title to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), deterministically — every run produces the same file.
